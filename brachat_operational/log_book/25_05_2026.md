# Report — Hermes Agent Setup
Date: May 25, 2026 | Version: 0.14.0 | Platform: macOS, Python 3.13

## Issues Found and Resolutions
1. Unknown provider: custom:groq  
   The `custom_providers:` block was missing from config.yaml. The syntax `custom:groq` is correct — only the provider declaration was missing.

2. Incorrect URL — HTTP 405  
   `base_url` was configured as `https://groq.com` (marketing site) instead of `https://api.groq.com/openai/v1`.

3. HTTP 413 — Token limit exceeded  
   Hermes' system prompt (~15,732 tokens) exceeds the free Groq plan limits. Tested `llama-3.3-70b-versatile` (12K TPM) and `llama-3.1-8b-instant` (6K TPM) — both insufficient. Solution: `meta-llama/llama-4-scout-17b-16e-instruct` (30K TPM).

4. Broken entry point  
   `hermes doctor` reported a required reinstallation with an invalid path (site-packages). Resolved with `pip install --force-reinstall hermes-agent`.

5. Context compression non-operational  
   Without an auxiliary provider configured, Hermes could not compress context when encountering a 413 error. Resolved by pointing the auxiliary provider to the same Groq endpoint.

6. Gateway without HTTP port  
   `hermes gateway run` does not open an HTTP port without an active messaging platform. Expected behavior in this version — access via `hermes chat`.
