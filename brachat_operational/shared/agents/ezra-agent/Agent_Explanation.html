🔌 Por que Web + Telegram?

Interface Web: perfeita para testar skills, depurar e usar direto no computador. Interface gráfica de chat com histórico.

Telegram Bot: operação remota, notificações, comandos rápidos. O mesmo agente pode ser usado no celular enquanto você está fora.

📡 Como a ligação funciona:
1. Um servidor central (Python/Node) carrega o agente com LLM, skills e memória.
2. Duas pontas: rota /chat para Web UI e webhook/long-polling para Telegram.
3. Cada mensagem chama o agente → ele planeja (macro) → escolhe skill → responde.
📱 Exemplo de uso no Telegram:
/ask Crie um plano de projeto usando a pasta Projetos
/skill xlsx Gerar relatório de oportunidades
/memoria Lembrar da última ideia
