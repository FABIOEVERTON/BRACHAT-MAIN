# Dependências e Stack (Baseline)

## Frontend (Marketing / Vitrine)
- HTML5, CSS3 Nativo, Vanilla JavaScript (sem frameworks adicionais até o momento no marketing).

## Backend (Especificado)
- Python 3.x
- FastAPI (`fastapi`, `uvicorn`)
- PostgreSQL 16 assíncrono (`asyncpg`, `alembic`, `SQLAlchemy`)
- Gestão de ambiente (`pydantic`, `python-dotenv`)

## Infraestrutura
- Docker Compose
- Banco de Dados: PostgreSQL 16 (Alpine) local via porta 5432.
