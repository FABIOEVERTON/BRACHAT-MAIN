# Convenções do Projeto

Este documento registra as convenções observadas no repositório:

- **Artefatos Wize:** Utilizam YAML frontmatter no topo dos arquivos Markdown para metadados e versionamento.
- **Identificadores (IDs):** Padrão de rastreabilidade utilizando prefixos como `AC-` (Critérios de Aceite), `ADR-` (Decisões de Arquitetura), `EPIC-` (Épicos).
- **Políticas:** As políticas globais de enforcement utilizam o prefixo `WIZE_` no nome do arquivo (ex: `WIZE_GLOBAL_ENFORCEMENT_POLICY.md`).
