# Story: Scaffold do monorepo (Turborepo + workspaces)

## Context

Base de tudo (PRD §2.1-2.2). Nenhum produto pode ser entregue sem o monorepo. Estrutura: `apps/web`, `apps/admin`, `services/shared`, `services/gov-ai/*`, `services/gov-municipal/*`, `packages/*`, `infra/`, `scripts/`, `docs/`, `turbo.json`, `package.json`, `pyproject.toml`.

## Sources of truth

- `AGENTS.md` + `.wize/config/project.toml` · `.wize/knowledge/document-project/*`
- `prd.md` (AC source) · `architecture.md` (ADR-001) · epic `E0-monorepo-core.md`
- TEA test contract para esta story · código relacionado já no path

## Acceptance criteria

- **F0-01:** Dado um diretório vazio em `platform/`, Quando o scaffold do monorepo é aplicado, Então `turbo.json`, `package.json` (workspaces), `pyproject.toml`, e os diretórios `apps/`, `services/`, `packages/`, `infra/`, `scripts/`, `docs/` existem.
- **F0-02:** Quando `npm install` + `npm run build` são executados na raiz, Então todos os workspaces TS compilam sem erro.
- **F0-03:** Quando `uv` ou `pip install -e` é executado no workspace Python, Então `services/shared` é importável a partir de qualquer serviço.

## Restrictions

- **Out of scope:** código de produto (S03+); auth; laudo engine.
- **Protected behaviors:** nenhum — scaffold inicial.
- **Compatibility:** Node ≥ 20; Python 3.12.

## Notes for Shuri (Dev)

- Touch points: `turbo.json`, `package.json`, `pyproject.toml`, `.gitignore`, diretórios §2.2 do PRD.
- Reuse: criar `packages/types` e `packages/ui` já no scaffold (mesmo que stubs compiláveis).
- Add: `"packageManager"` e engines no root package.json.

## Validation contract

- **AC → test:** F0-01 → smoke test de existência dos paths; F0-02 → `turbo build` green; F0-03 → import test `from services.shared import ...`.
- **Required checks:** install, build, type-check TS strict (ADR via arquitetura), import Python.
- **States:** estado vazio (sem scaffold) → scaffold aplicado.

## Notes for Hawkeye (TEA)

- Tests: 1 script de smoke (paths), 1 build check, 1 import check Python.
- NFR sample: build da raiz ≤ 3min em dev machine.

## Done means

Scaffold compila; smoke test de paths PASS; import Python OK; gate PASS/CONCERNS; story `ready-for-review`.
