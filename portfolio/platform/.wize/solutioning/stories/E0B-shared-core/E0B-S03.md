# Story: scripts/seed_controls.py — 122 controles AGCP

## Context

Seed dos 122 controles do framework AGCP (PRD §4.2): L1 Jurídico 38 (PL 2338, LGPD), L2 Dados 31 (LGPD, ANPD Res. 2/2022), L3 Segurança 28 (ISO 42001, NIST AI RMF, ISO 27001), L4 Perícia 25 (CPC 464-480, Res. CFO 1.389/2012). Cada controle com control_id, control_name, level, normative_refs (norma+artigo+cláusula).

## Sources of truth

- `prd.md` (§4.2 — estrutura ControlResult/BaseControl, distribuição 38/31/28/25) · epic E0B · TEA contract
- `services/gov-ai/aegis/controls/base.py` (control_id, level, normative_refs) do PRD

## Acceptance criteria

- **F0B-11:** Dado o seed executado, Quando popula o banco, Então existem exatamente 122 controles com distribuição L1:38, L2:31, L3:28, L4:25.
- **F0B-12:** Quando um controle é consultado, Então tem control_id único no formato L{n}-NNN e normative_refs preenchidos com norma, artigo e cláusula.
- **F0B-13:** Quando o seed roda duas vezes, Então é idempotente (não duplica registros; upsert).
- **F0B-14:** Quando um controle referenciado por laudo/normative_map é removido, Então o sistema detecta órfãos (integridade referecial).

## Restrictions

- **Out of scope:** lógica de avaliação dos controles (FASE 1 — classes BaseControl evaluate); scoring/RIPD (FASE 1).
- **Protected behaviors:** os 122 controles são o contrato jurídico — nenhum pode ser removido sem ADR + revisão jurídica.
- **Compatibility:** SQLAlchemy; execução via `scripts/seed_controls.py` (convenção do PRD §2.2).
