# Story: MFA compulsório + SSO corporativo

## Context
Admin/auditor só obtêm escopo elevado após TOTP; Enterprise integra SSO (SAML 2.0 / OIDC).

## Sources of truth
`prd.md` §2.4 Auth · `architecture.md` §4 · `nfr-principles.md` SEC-3 · `tea-risk.md` R-7

## Acceptance criteria
- **AC-01-D2 (derivado):** Dado admin sem TOTP validado, Quando acessa rota sensível, Então token com escopo `mfa:pending` é rejeitado (403), e o refresh token rotativo invalida em reuso.

## Restrictions
- **Out of scope:** fine-tuning de políticas de senha → não no MVP.
- **Protected behaviors:** access token 15 min; refresh 7 dias com rotação.
- **Security:** Argon2id; JWE RS256; segredo TOTP cifrado.

## Validation contract
- **AC → test:** AC-01-D2 → segurança: acesso sem TOTP → 403; replay de refresh → negado.
- **Required checks:** lint, type-check, build, scan de segredo.
- **States:** sem MFA, aguardando TOTP, autenticado.
