# Story: Upgrade pro-rata via webhook idempotente

## Context
Upgrade Professional → White-Label Pro libera cota imediatamente após confirmação de pagamento, sem quebrar cadeia de custódia.

## Sources of truth
`prd.md` Épico 5/História 5.1 (upgrade) · `architecture.md` §1 Fronteira D · `tea-risk.md` R-8

## Acceptance criteria
- **AC-05-3:** Dado tenant Professional que conclui upgrade, Quando o webhook (Stripe/Pagar.me) é confirmado, Então recalcula o valor *prorata*, libera imediatamente a nova cota e mantém laudos/manifestos anteriores acessíveis sem recompilação.

## Restrictions
- **Out of scope:** downgrade/estorno → pós-MVP.
- **Protected behaviors:** webhook duplicado tem efeito idempotente; assinatura verificada.
- **Security:** mudança de cota só por evento válido assinado.

## Validation contract
- **AC → test:** AC-05-3 → integração webhook válido → cota liberada + prorata; webhook duplicado → 1 efeito; assinatura inválida → 401 sem mudança.
- **Required checks:** lint, type-check, build, verificação de assinatura.
- **States:** pendente, confirmado, duplicado, inválido.
