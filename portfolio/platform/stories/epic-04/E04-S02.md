# Story: Gateway MCP deny-by-default + trilha indelével

## Context
Casos 2 e 3 do Épico 4: ferramenta desconhecida é negada; toda chamada gera linha auditável com hash do payload.

## Sources of truth
`prd.md` Épico 4/Cenários 2–3 · `architecture.md` §1 Fronteira C · `ADR-003` · `tea-risk.md` R-3

## Acceptance criteria
- **AC-04-2:** Dado ferramenta fora do ACL do tenant, Quando a chamada passa pelo gateway, Então é negada por padrão, classificada `UNKNOWN_TOOL`, registrada no Decision Ledger e o admin é notificado com sugestão de permissão explícita.
- **AC-04-3:** Dado qualquer ferramenta acionada, Quando o gateway encerra a chamada, Então grava em `Audit_Logs` agente autor, ferramenta, resultado (APROVADO/NEGADO/RETIDO) e hash SHA-256 do payload, com retenção indelével.

## Restrictions
- **Out of scope:** fluxo de aprovação HITL → E04-S03.
- **Protected behaviors:** nenhuma chamada executa antes da checagem de ledger.
- **Security:** hash do payload obrigatório; budget de gate < 50 ms p95.

## Validation contract
- **AC → test:** AC-04-2 → integração ferramenta desconhecida → negado + ledger + notificação; AC-04-3 → integração qualquer chamada → linha completa em Audit_Logs.
- **Required checks:** lint, type-check, build, latência de gate.
- **States:** permitido, negado, retido.
