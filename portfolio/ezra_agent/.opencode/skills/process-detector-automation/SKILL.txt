SKILL process-detector-automation | S27 | cluster integracao
DESC: Identifies repetitive tasks and implements intelligent automations with detection, implementation and ROI measurement.
OBJ: Identify repetitive tasks and implement intelligent automations (Pascal Bornet methodology) from detection to ROI measurement.
IN: Activity logs, pattern observations. Candidate process and baseline metrics (time, cost, errors).
OUT: Classified task (COPY-PASTE, RECURRING DECISION, etc.) with automation score. Decision: AUTOMATE_NOW, AUTOMATE_SESSION, CREATE_TEMPLATE, KEEP_MANUAL. Process Audit, Architecture (A/B/C/D), Build, measured ROI, Knowledge Transfer.
DEPS: SK-023 (Agent Factory) if pattern C or D (new agent). Guideline: MCP brachat-mcp boundary (API keys via mcp_secrets_get) or Composio for external automations.
BUDGET: 400-800 per detection + 2000-5000 per complete automation.
COST: High. Detection is light, but implementation + test + measurement consume.
SEC: Logs may contain operational data — mask first. Automations with external access pass HITL. Every automation must have documented rollback.
TESTS: 1. Detected pattern with 3+ repetitions? 2. Score correctly reflects frequency/time/complexity? 3. Time saved > 50%? 4. ROI > 3x in 3 months? 5. Knowledge Transfer allows safe deactivation?
