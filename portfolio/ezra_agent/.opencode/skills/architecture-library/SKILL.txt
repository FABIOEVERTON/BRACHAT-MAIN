SKILL architecture-library | S06 | cluster arquitetura
DESC: Maintains and queries a library of reusable components to reuse solutions instead of reinventing them.
OBJ: Maintain and query a library of reusable components (Harness Patterns, Loop Patterns, Memory Patterns, Governance Patterns, Skill Patterns, Agent Patterns, Prompt Patterns) to reuse solutions instead of reinventing them.
IN: Pattern query ("I need a loop with checkpoint pattern"). New pattern to catalog. Problem context.
OUT: Most relevant pattern returned with: name, description, when to use, example, estimated cost. Cataloged pattern with metadata (type, version, dependencies, tags).
DEPS: SK-013 (Systems Thinking) to analyze which pattern applies. SK-001 (Spec) to adapt pattern to context.
BUDGET: 400-800 tokens per query or catalog.
COST: Low. Local library query.
SEC: Patterns must not contain credentials or client-specific data. Pattern use is a recommendation, not automatic decision — always pass through Governance.
TESTS: 1. Returned pattern most relevant to problem? 2. No-match query returned useful fallback? 3. Cataloged pattern has complete metadata?
