## Objective

Build a minimal Python project that uses `shutil.disk_usage` to read disk usage statistics for a given path and saves the formatted output to a `.txt` report file.

## Deliverables

| File | Description |
|---|---|
| `vm_disk_probe_test.py` | Main script: accepts a path argument, calls `shutil.disk_usage`, prints and writes results |

| `disk_report.txt` | Output file generated by the script containing total, used, and free disk space |

## Technical Specification

### Project Location

```
portfolio/vm_disk_probe_test/
```

### Script: `vm_disk_probe_test.py`

- Accept optional path argument via `sys.argv` (default: `"/"`)
- Call `shutil.disk_usage(path)` to obtain `total`, `used`, `free` bytes
- Convert bytes to human-readable format (GB with 2 decimal places)
- Print report to stdout
- Save identical report to `disk_report.txt` in current working directory
- Use `if __name__ == "__main__":` guard
- Exit code 0 on success, 1 on error

### Test: `test_vm_disk_probe.py`

- Use `unittest.TestCase`
- Test 1: `test_valid_path` — run script via `subprocess.run` with `"/"`, verify exit code 0, verify `disk_report.txt` exists and contains expected fields (`Total`, `Used`, `Free`)
- Test 2: `test_invalid_path` — run script with nonexistent path, verify exit code 1
- Test 3: `test_permission_denied` — mock `shutil.disk_usage` to raise `PermissionError`, verify exit code 1
- Test 4: `test_no_args_default` — run script with no arguments, verify exit code 0, verify `disk_report.txt` contains valid GB values

### Output Format (`disk_report.txt`)

```
Disk Usage Report for: /
Total: XXX.XX GB
Used:  XXX.XX GB
Free:  XXX.XX GB
```
