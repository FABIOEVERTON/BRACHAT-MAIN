# ROADMAP ÚNICO — Filho, 16 anos → Carreira Tech via Estatística (UnB)

> **Baseado em**: 8 CEOs (Altman, Huang, Nadella, Zuckerberg, Musk, Amodei, Hassabis, Pichai), 14 instituições (WEF, BLS, McKinsey, Stanford HAI, OECD, IMF, BCG, Deloitte, PwC, Gartner, Accenture, Brasscom, Dice, Levels.fyi), The World Ahead 2026 (7 artigos), WEF Four Futures 2030, currículo UnB Estatística, mercado Brasil.
> **Tese central**: Estatística na UnB + certificações técnicas + optativas de computação = profissional mais preparado para 2027-2036 do que CS puro.
> **Atualizado**: 10 Jun 2026

### Decisão: Estatística (Bacharelado, UnB)

**Por que não CS?**
- CS entry-level é o mais vulnerável a AI (o "bottom rung" que o The Economist descreve)
- Mercado entry-level CS global já mostra saturação (NY Fed: 5.7% desemprego)
- CS na UnB não é melhor que Estatística na UnB para o mercado de dados/AI

**Por que Estatística na UnB especificamente?**
- Base matemática pesada: 12 disciplinas de cálculo, álgebra linear, probabilidade, inferência
- 960h de optativas livres — pode pegar Estrutura de Dados, BD, Python, ML, Econometria
- Localizada em Brasília — acesso a HUB de IA, EMBRAPA, IPEA, órgãos públicos, startups
- Curso menos concorrido que CS na UnB — maior chance de passar
- Estatístico é profissão regulamentada e reconhecida internacionalmente

**Por que não Biologia primeiro (tese Huang)?**
- Mercado biotech brasileiro ainda imaturo para entrada direta
- Estatística + optativas de biologia + mestrado em bioestatística = mesma rota, mais seguro
- O biólogo brasileiro ganha menos que o estatístico brasileiro na média

## FASE 2 — INÍCIO DE CARREIRA (Jan 2033 — Dez 2035)
**Idade: 23-25 anos | Objetivo: Primeiro emprego full-time, especialização**

### Cenário de mercado projetado (2033-2035)

Baseado na pesquisa 360° + The World Ahead 2026:
- AI já automatizou entry-level de CS (bottom rung desapareceu)
- Profissionais com **base estatística + programação + certificações** são raros e bem pagos
- Mercado brasileiro de dados: salários entre R$ 12-30K para pleno
- Estatísticos com skills de ML ganham 30-50% mais que estatísticos tradicionais
- Biologia computacional (tese Jensen Huang) está em expansão

### Rotas possíveis de carreira

#### Rota A — Data Science / ML (mais provável, maior salário)
```
Estagiário → Data Scientist Jr → ML Engineer → ML Engineer Pleno
Salário: R$ 5-8K → R$ 10-15K → R$ 15-22K → R$ 22-35K (Brasil)
```
**Empresas alvo**: HUB IA, Nubank, VTEX, Ifood, startups dados, bancos

#### Rota B — Bioestatística / Health Analytics (tese Huang)
```
Estagiário → Bioestatístico Jr → Health Data Analyst → Bioestatístico Pleno
Salário: R$ 4-7K → R$ 8-12K → R$ 12-18K → R$ 18-28K (Brasil)
```
**Empresas alvo**: Eurofarma, Hypera, EMBRAPA, Anvisa, hospitais, CROs
**Vantagem**: Menos concorrência que ML, mercado aquecido (semaglutida 2026+)

#### Rota C — Data Engineering
```
Estagiário → Data Engineer Jr → Data Engineer → Data Engineer Pleno
Salário: R$ 6-9K → R$ 12-18K → R$ 18-28K → R$ 25-40K (Brasil)
```
**Empresas alvo**: Qualquer empresa com dados em escala
**Vantagem**: Engenharia é mais blindada contra AI que ML puro

#### Rota D — Consultoria / Quant (internacional)
```
Estagiário → Analyst → Consultant / Quant → Senior
Salário: R$ 8-12K → R$ 15-25K → R$ 25-50K+ (Brasil) ou $80-150K (exterior)
```
**Empresas alvo**: McKinsey, BCG, Bain (dados), ou Quant funds (BTG, Itaú, XP)
**Vantagem**: Salário mais alto, mas mais estresse e menos flexibilidade

### Recomendação: Rota A + B combinada

**O filho pode fazer os 4 estágios em áreas diferentes e decidir na reta final da faculdade.**

Sugestão prática para 2033-2035:
1. **Primeiro ano (2033)**: Data Science Jr em startup tech ou HUB IA — ganha experiência rápida
2. **Segundo ano (2034)**: ML Engineer Jr — aplica estatística em problemas reais
3. **Terceiro ano (2035)**: ML Engineer Pleno OU migra para health analytics

## CENÁRIOS POSSÍVEIS (com base na pesquisa)

### Pessimista (20% de chance — AI avança muito rápido, Brasil em crise)
- Filho se forma em Estatística e mercado entry-level está comprimido
- **Proteção**: certificações pesadas (CKA, Terraform, Databricks) abrem portas mesmo em crise
- **Plano B**: aceitar salário menor por 1-2 anos, migrar para cargo de dados em empresa tradicional

### Base (60% de chance — cenário mais provável)
- Mercado de dados cresce 15-25% ao ano no Brasil
- Estatístico com certificações técnicas é perfil raro e bem remunerado
- Filho atinge R$ 15-25K em 3-5 anos

### Otimista (20% de chance — boom AI no Brasil, biotech decola)
- Mercado de dados explode (WEF: 170M empregos criados globalmente)
- Biologia computacional decola (tese Jensen Huang)
- Filho com Estatística + bioestatística + certificações = perfil ideal
- Salário > R$ 40K em 5 anos

## AVISOS CRÍTICOS

1. **Não confiar só no diploma** — Estatística (UnB) + certificações + portfólio + estágios. Os 4 juntos.
2. **Inglês é condição, não diferencial** — sem C1, perde 50% das oportunidades
3. **Não fazer CS na UnB em vez de Estatística** — CS tem bottom rung mais frágil (The World Ahead 2026)
4. **Não fazer Biologia em vez de Estatística** — biotech brasileiro não está maduro para primeiro emprego; biologia como especialização (mestrado ou optativas)
5. **Não pular certificações** — CKA + Terraform + Databricks + Cloud são o que separa o estatístico de R$ 8K do estatístico de R$ 25K
6. **Não ignorar estágios** — 4 estágios em áreas diferentes = 4x mais chance de acertar na escolha de carreira
7. **AI vai mudar o mercado entre 2028 e 2032** — mas a base (matemática + estatística + programação) é perene. Quem tem base se adapta; quem só sabe ferramenta morre.
