# PARTE 7 — IA E AUTOMAÇÃO

## Classificação de risco por grupo de profissões

### Alto risco de substituição
- Caixas, atendentes
- Assistente administrativo, secretária
- Contador (rotineiro)
- Tradutor
- Operador de manufatura
- Entrada de programação (junior coding)
- Suporte nível 1

### Médio risco (remodelação significativa)
- Desenvolvedor full stack
- Frontend engineer
- Analista de dados
- Designer gráfico
- Redator/produtor de conteúdo
- Analista financeiro
- Paralegal
- Customer service

### Baixo risco (AI amplia, não substitui)
- Enfermeiro, médico
- Cientista de pesquisa
- Arquiteto de segurança
- Arquiteto de soluções
- Engenheiro de software sênior
- Gerente de produto
- Skilled trades (eletricista, encanador)
- Professor (presencial)
- Psicólogo, terapeuta

### Beneficiados pela AI
- Cientista de dados (AI acelera análise)
- ML Engineer (AI automatiza ML básico, libera para avançado)
- Product Manager (AI dá dados melhores)
- Pesquisador (AI acelera descobertas)
- Arquiteto cloud (AI automatiza operação, foco em design)
- Especialista em segurança (AI detecta, humano decide)

# SÍNTESE EXECUTIVA — RECOMENDAÇÕES PRÁTICAS

## Para maximizar empregabilidade, renda e resiliência (2026-2035)

### 1. Estratégia educacional (em ordem)
1. **Base técnica sólida** — CS, Estatística ou SWE (graduação ou equivalente autodidata)
2. **2-3 certificações de alto valor** — CKA + Terraform + Cloud (AWS/Azure) OU Databricks + Snowflake (dados)
3. **Mestrado em AI/ML** — apenas se focado em pesquisa ou transição para AI core
4. **MBA top20** — apenas se ambicionar C-level ou transição executiva
5. **PhD** — apenas para AI research em FAANG ou academia

### 2. Stack de competências recomendada

| Camada | Competências | Prioridade |
|---|---|---|
| Fundação | Python, SQL, Cloud (AWS/Azure/GCP), Linux, Git | Essencial (hoje) |
| Núcleo | Kubernetes, Terraform, CI/CD, Arquitetura de Sistemas | Essencial (2026-28) |
| Diferencial | Agentic AI, RAG, LLMOps, Vector Databases, MLOps | Crítico (2027-30) |
| Humano | Pensamento crítico, liderança, comunicação, adaptabilidade | Perene |
| Domínio | Expertise em 1-2 indústrias (saúde, energia, governo, finanças) | Premium |

### 3. Roteiro de carreira 2026-2035

**Fase 1 (2026-2028): Construir fundação**
- Dominar Python, SQL, Cloud (AWS Solutions Architect Associate)
- Obter CKA + Terraform Associate
- Construir portfólio público (GitHub com projetos reais)
- Entrar em AI/ML via dados (Data Engineer → ML Engineer)

**Fase 2 (2028-2030): Especializar em AI**
- Mestrado ou especialização em AI/ML
- Certificação Google ML Engineer ou AWS ML Specialty
- Foco em Agentic AI, LLMOps, RAG
- Transição de executor para orchestrator de AI agents

**Fase 3 (2030-2035): Liderança ou pesquisa**
- Opção A: AI Product Manager / Tech Lead (MBA se necessário)
- Opção B: Principal/Staff Engineer (PhD se necessário)
- Opção C: Empreendedor (AI-enabled consulting ou produto próprio)

### 4. Avisos importantes

1. **Entry-level tech está saturando** — portfólio + certificações já são diferenciais obrigatórios
2. **Cargo de "Prompt Engineer" é transitório** — será absorvido por Product Manager e ML Engineer em 2-3 anos
3. **Full Stack e Frontend têm maior risco de automação** — compensar com profundidade em infraestrutura
4. **AI literacy é baseline, não diferencial** — todo profissional tech precisa saber usar AI, não é mais um "plus"
5. **Agentic AI é o breakout** — a habilidade de orquestrar múltiplos AI agents autônomos será a competência mais valiosa de 2027-2030
6. **Saúde é o setor mais resiliente** — combina crescimento inorgânico (BLS) + alta resistência à automação
7. **Cybersecurity tem o melhor risk/reward** — 29% crescimento, alta resistência AI, escassez severa
8. **Cloud + Kubernetes + Terraform** é a combinação mais estável — tecnologia madura, demanda perene
