# Official Unified Schedule — BRACHÁT

## Estrutura

- **Fase** → **Módulo** → **Dia-a-dia** (teoria + hands-on + entrega)
- Progressão por **domínio comprovado**: só avança quando entrega o checkpoint
- O orquestrador cobra diariamente: "Qual materia voce esta? Entregou o checkpoint? Entao vamos pro proximo."
- Cada dia usa um dos slots da rotina (07:30, 08:00, 08:30, 11:00, 17:00, 20:00)

### Mapa de Slots

| Slot | Horário | Matéria |
|------|---------|---------|
| Inglês | 07:30-08:00 | **Fase 3** — Inglês Técnico (diário) |
| Estudo Principal | 08:00-08:30 | **Fase atual** — módulo ativo do cronograma |
| Google Skills | 08:30-09:00 | **Fase 4.2** — Google Skill do dia (ou fase atual se concluído) |
| Deep Work AM | 09:00-11:00 | Estudo aprofundado + hands-on da **fase atual** |
| Python | 11:00-12:00 | **Fase 2** — Python Masterclass (quando ativo) |
| Deep Work PM | 14:00-17:00 | Job hunting + hands-on continuado |
| Portfólio | 17:00-18:00 | Projeto prático convertido em post/link |
| Torá/Filosofia | 20:00-21:00 | Obrigatório diário (fixo) |
